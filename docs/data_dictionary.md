# Data dictionary

Generated by `scripts/generate_data_dictionary.sh` from the comments stored in Oracle:
`COMMENT ON TABLE` and `COMMENT ON COLUMN`, plus `EXT_TABLE_DOC` for the external tables,
which Oracle can't comment. Don't edit this file by hand. Change the comment in `db/` and
run the script again.

23 tables, 4 external tables and 12 views, with 465 columns between them. Every one has a description.
