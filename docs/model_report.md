# PD model report

Generated by `python/train_pd_model.py` on 2026-10-13. Model version `PD_LR_20261013_091845`. Every number below comes from that run.

## Data

- Source: `LOAN_DEV`, 250,000 closed loans from matured vintages (see `docs/data_profile.md`).
- Training: loans issued Jun 2007 to Dec 2014, 145,617 loans, default rate 14.77%.
- Out-of-time test: loans issued in 2015, 104,383 loans, default rate 14.82%. The model never sees this period while training, so the test shows how it holds up on a later vintage.
- Target: `default_flag` = 1 for charged off, 0 for fully paid, over the loan's full term.

## Features

Application-time information only:

- Numeric (median imputation, capped at the training 1st and 99th percentiles except `fico`, then standard scaling): `loan_amnt`, `funded_amnt`, `int_rate`, `installment`, `log_annual_inc`, `dti`, `delinq_2yrs`, `fico`, `credit_history_months`, `inq_last_6mths`, `open_acc`, `pub_rec`, `log_revol_bal`, `revol_util`, `total_acc`, `mort_acc`, `pub_rec_bankruptcies`.
- Categorical (one-hot, missing as its own category): `grade`, `term_months`, `home_ownership`, `verification_status`, `purpose`, `emp_length`, `application_type`.
- Derived: `fico` = midpoint of `fico_range_low` and `fico_range_high`; `credit_history_months` = `issue_d` minus `earliest_cr_line`; `log_annual_inc` and `log_revol_bal` = log(1 + x).

Excluded because they are only known after the loan has run (leakage); `prepare_data.py` and this script assert none of them is a model input:

`collection_recovery_fee`, `debt_settlement_flag`, `last_credit_pull_d`, `last_pymnt_amnt`, `last_pymnt_d`, `next_pymnt_d`, `out_prncp`, `out_prncp_inv`, `pymnt_plan`, `recoveries`, `total_pymnt`, `total_pymnt_inv`, `total_rec_int`, `total_rec_late_fee`, `total_rec_prncp`, and every column starting with `last_fico_range_`, `hardship_`, `settlement_`.

## Method

scikit-learn `Pipeline`: `ColumnTransformer` (numeric and categorical branches) feeding a `LogisticRegression` (lbfgs, L2 penalty, C = 1.0). No class weighting and no resampling, because re-weighting defaults would inflate every predicted PD and the ECL needs real probabilities.

## Live book: origination PD

All 100,000 loans in `LOAN_MASTER` were scored with their application data. The model's term PD was converted to a 12-month PD with a constant hazard, PD_12m = 1 - (1 - PD_term)^(12/T), then floored at PD_FLOOR = 0.0005 from the XML config (0 loans were raised to the floor).

## Limitations

- The target is default over the full term; the 12-month PD comes from a constant-hazard assumption, while real default hazards peak in the first years of a loan.
- Monthly scoring swaps today's FICO into a model trained on origination FICO (a stated simplification).
- Matured vintages end in 2015, so the model reflects 2007-2015 underwriting and economic conditions.
